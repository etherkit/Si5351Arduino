# Flash ceilings for arduino:avr:uno. A sketch larger than its budget FAILs.
# A smaller sketch still passes: this is a non-regression ceiling, not a claim
# that the library got faster.
#
# Reproduced 2026-11-08 with:
#   arduino-cli 1.5.1 (commit 01f3d4f2b)
#   arduino:avr 1.8.6
#   avr-gcc 7.3.0-atmel3.6.1-arduino7
#   fqbn arduino:avr:uno
#   core flags from platform.txt: -Os -flto -fpermissive -std=gnu++11
#     -fno-exceptions -ffunction-sections -fdata-sections -fno-threadsafe-statics
# Size method: arduino-cli "Sketch uses N bytes", which is avr-size text+data.
# The checker also requires avr-size text+data == N. A parse miss is a FAIL.
#
# v2.4.2 baselines on this pin: min_const 10830, min_runtime 11558.
# The audit runtime-clock sketch was not saved (REPORT only, no .ino), so its
# reported 12604 bytes cannot be compared with min_runtime and is not a target.
# min_runtime is a global volatile uint8_t clock index and a constant 14 MHz.
# min_runtime_no_clk67 is that program compiled with -DSI5351_NO_CLK67.
# Ceilings below are the sizes after the PLL and init/reset merge, so a
# later edit cannot grow back to the v2.4.2 baseline.
min_const 10140
min_runtime 10868
min_runtime_no_clk67 9836
# min_runtime_sketch_no_clk67: same program with #define SI5351_NO_CLK67 in the
# sketch (no compiler flag). A library that ignores the define builds 10930.
min_runtime_sketch_no_clk67 9870
# min_runtime_sketch_no_vcxo: same program with #define SI5351_NO_VCXO in the
# sketch (no compiler flag). A library that ignores the define builds 10868.
min_runtime_sketch_no_vcxo 10428
# Both sketch defines. A library that honors only SI5351_NO_CLK67 builds 9870.
min_runtime_sketch_no_clk67_no_vcxo 9390
